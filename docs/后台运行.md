# Windows 后台运行

运行 `install_autostart.ps1` 注册当前用户的 `GenAI2OpenAI-Local` 计划任务。
任务在该用户登录 Windows 时启动，使用当前交互用户的普通权限，不保存密码、不以管理员身份运行。
它通过 `.venv/Scripts/pythonw.exe run_managed.py` 启动服务，不弹出控制台。
项目位置移动或虚拟环境重建后，需要重新运行安装脚本。

## 自动恢复

- 反代子进程退出后，守护程序记录退出码并等待 10 秒，然后重新启动。Windows 计划任务负责登录启动守护程序；虽配置了一分钟失败重试，但本机验收未观察到该机制恢复，因此不依赖它。
- 没有默认的三天运行时限；使用电池时也不停止。
- 任务禁止并行实例。5057 端口被占用时不启动第二个服务器，守护程序每 10 秒重试。
- 仍只监听 `127.0.0.1:5057`，不开放局域网访问。
- 这是登录自启动：注销期间或尚未登录时不会运行，也不会唤醒休眠的电脑。
- 自动恢复针对反代子进程退出，不把单次学校接口超时、空回复当成进程故障；也不检测进程卡死。

## 管理命令（PowerShell）

```powershell
# 查看状态
Get-ScheduledTask -TaskName 'GenAI2OpenAI-Local'
Get-ScheduledTaskInfo -TaskName 'GenAI2OpenAI-Local'

# 手动启动托管服务
Start-ScheduledTask -TaskName 'GenAI2OpenAI-Local'

# 停用登录自启并停止当前任务
Disable-ScheduledTask -TaskName 'GenAI2OpenAI-Local'
Stop-ScheduledTask -TaskName 'GenAI2OpenAI-Local'

# 恢复自启，再立即启动
Enable-ScheduledTask -TaskName 'GenAI2OpenAI-Local'
Start-ScheduledTask -TaskName 'GenAI2OpenAI-Local'
```

启用托管后，不必再打开 `start_local.cmd`，避免启动重复实例。
诊断日志为 `logs/server-managed.log`，包含启动时间、子进程 PID、退出码和应用错误。
日志超过 5 MiB 时在下一次子进程启动轮换，保留一个旧文件；单次长运行中的日志暂不轮换。
日志和凭据均已被 Git 忽略，任务参数中没有学校 Token。
